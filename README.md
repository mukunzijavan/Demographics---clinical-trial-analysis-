# Demographics---clinical-trial-analysis-
A clinical programming project demonstrating end-to-end clinical trial demographics and baseline analysis using both SAS and R, following CDISC/SDTM/ADaM principles and clinical reporting standards.

The project shows the translation of the same analysis workflow across SAS and R, from ADaM-style data processing and treatment-group derivation to statistical summarization and production of reporting-ready TLFs.
What This Project Demonstrates
SAS & R clinical programming and cross-language analytical translation

CDISC concepts: SDTM, ADaM, and analysis populations

Demographic and baseline characteristic summaries

Treatment-group counts, percentages, and descriptive statistics

Subject-level data processing and analysis dataset preparation

Clinical table development and formatting

Tables, Listings, and Figures (TLFs)

PDF generation and review of final reporting outputs

Reproducible clinical programming practices

SAS & R Outputs
The repository contains both the SAS and R source code and their corresponding PDF outputs, allowing the analysis workflow and final reporting results to be reviewed side-by-side.
